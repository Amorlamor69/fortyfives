# Forty-Fives

The Merrimack Valley card game, played in the browser.

- Rules: Merrimack Valley style. Trump runs 5, J, A♥, A, K, Q, then high in red and low in black. Bids 15 to 30, game to 120.
- Modes: Solo, Head-to-Head, Partners, Cutthroat, plus Night Out, a tour of ten classic Valley bars with trivia.
- Lessons, drills and a coached game for new players.

Everything runs in the browser. Progress is saved on the player's own device.

## Publishing

This folder is a complete static website. On GitHub: Settings → Pages → Deploy from a branch → `main` / root.
